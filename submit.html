分享一个作品取景地

跟着地图选点、填写场景、确认后提交。提交会打开一个 GitHub 投稿页面，登录 GitHub 提交 Issue；核对通过后才会显示在地图上。

  1. 1 选择
  2. 2 地点与场景
  3. 3 检查提交

新作品填写中文名或韩文名即可。

输入后从建议中选择地点。

先在地图上点击位置，坐标会自动填入；也可以在下面修改。暂不确定精确机位也可以投稿。

场景、图片或更正资料，填写其中一项即可。图片可在下一步添加。

不确定来源可以留空；审核时会按资料情况标注。
