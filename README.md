# 剧场之外 · 韩国影视综艺取景地地图

> 目前处于取景地搜集阶段，欢迎大家多多投稿。打开地图，点击「投稿地点」就能提交新地点、场景截图或更正资料；提交时会跳转 GitHub 提交 Issue。

[打开地图](https://zurizhao.github.io/kdrama/)

跟着喜欢的电视剧、电影和综艺探索取景地。你可以按作品查找地点，在地图上查看位置、场景介绍和资料来源，也可以保存想去的地点，安排自己的巡礼路线。

## 开始使用

1. 打开地图，在左侧搜索作品，或按地区、近期更新、热门作品浏览。地区列表包含韩国 17 个一级行政区划及韩国境外；点击地区后会显示该地区有取景地的作品。
2. 选择作品后，按地点分组或集数查看取景地。没有集数或分组的地点会显示在“未分组”。没有地点的作品也可以先浏览，等待投稿补充。
3. 点击地点列表或地图标记，查看地点详情、来源与导航入口。
4. 将感兴趣的地点加入收藏或行程。出发前请再次核对开放时间、交通和现场情况。

地图还支持查找附近地点、记录到访和使用当前位置签到。收藏、行程与到访记录仅保存在当前浏览器；换设备或清除浏览器数据后不会自动恢复。定位只用于当前页面计算距离和签到。

地点密集时会显示数量，点击可展开地点列表或继续放大；同坐标的地点也能分别选择。进入作品后，点击分组或集数标题可以筛选地图，点击“显示全部”恢复。手机端可切换列表的收起、半屏和展开状态；分享地址、刷新和浏览器返回会保留当前浏览位置与筛选。

在“我的行程”中可以分享地点顺序，或展开“备份与导入个人记录”导出收藏、到访和签到日期。换设备后导入备份即可恢复；导入前会显示数量，默认合并并保留本机记录。别人分享的行程先显示预览，点击“加入我的行程”才会保存。地图上的行程虚线只连接地点，并非实际道路路线。

地点详情中的“制作实拍对比图”可将场景截图与自己的照片并排或滑动对比，并下载图片。实拍照片只在浏览器处理，不会上传。

## 分享取景地

发现了新的取景地、场景资料，或发现现有地点有误？在地图上点击位置并选择“在此提交取景地”，也可以点击“投稿地点”。输入中文名、韩文名或别名搜索作品，选中后填写地点与场景。已有地点可在同一个入口补充场景、图片或更正名称和坐标。文字草稿自动保存在当前浏览器，恢复草稿后需要重新选择图片。

资料来源、集数、时间点和地点分组均可留空。新作品填写中文名或韩文名并选择电视剧、电影或综艺；海报可以不上传，取景地坐标可以位于世界任何地区。场景图片也是可选项，提交前可预览地图卡片的裁剪效果。上传图片或海报时请确认有展示许可，署名可选。投稿先进入待审核区，审核通过后才会出现在地图上；“近期更新”按审核通过时间排序。缺少来源的地点会标为“待核实”。

一次可选择最多 12 张场景图片，每张不超过 5 MB，支持 JPG、PNG、WebP。每张图可以独立填写集数、时间、描述和署名，也能调整裁剪位置。到 GitHub 后请按编号将原图放入对应图片区块；图片较多时需复制完整正文粘贴到 GitHub。地图发布时会为新投稿的 GitHub 场景图片生成缩略图，放大查看仍可读取原图。

点击“前往 GitHub 完成投稿”后，登录 GitHub，将已选择的场景图片／海报放进对应区块，等待上传完成，再点击 **Submit new issue**。本页选图用于预览，不会自动上传到 GitHub。打开 GitHub 页面还不算提交成功；提交后可把 Issue 链接或编号填入投稿页的进度查询，查看是否待审核、需要补充或已发布。只有线上地图已经包含这条投稿时，才会显示“已发布”和地点直达链接。

## 使用提醒

目前是试运行版本，已有地点中包含**示意点**，不能据此认定精确拍摄机位。新增地点的逐条核验情况见[核验记录](data/verification-2026-11-07.md)。现场可能因营业、施工或私人区域限制而无法进入；请遵守当地规定。

街道底图由 [OpenFreeMap](https://openfreemap.org/) 提供，使用 OpenStreetMap 数据；地图服务不可用时会显示韩国轮廓图。本站参考 [Anitabi](https://navi.anitabi.cn/docs/) 的作品、地标与场景组织方式，不使用其地点数据或截图。

## 站点维护

投稿集中在仓库的 [GitHub Issues](https://github.com/ZuriZHAO/kdrama/issues)。打开[可视化审核页](https://zurizhao.github.io/kdrama/review.html)，输入 Issue 链接或编号，用表单、地图拖点和图片预览修订，生成正文后回原 Issue 保存。维护者确认后添加 `publish-approved` 标签，工作流会自动导入并发布，成功或失败都会回写处理结果。审核页本身不会授予仓库写入权限。操作细节见[维护者说明](docs/MAINTAINER.md)；手工添加作品或修改海报见[预置作品与海报说明](docs/works.md)。

审核页的“投稿队列”可按待审核、待补充、发布失败和已发布标签浏览。[维护已发布内容](https://zurizhao.github.io/kdrama/manage.html)可修改作品设置、地点分组与排序、指定场景，或合并重复地点。所有变更先生成清单，再通过 GitHub 审核发布。
