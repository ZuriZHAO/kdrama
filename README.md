# 剧场之外 · 韩剧取景地地图

> 当前为试运行版本。源码仓库已公开。

[打开地图](https://zurizhao.github.io/kdrama/)

跟着喜欢的韩剧探索取景地。你可以按作品查找地点，在地图上查看位置、场景介绍和资料来源，也可以保存想去的地点，安排自己的巡礼路线。

## 开始使用

1. 打开地图，在左侧搜索或选择一部韩剧。
2. 点击地点列表或地图标记，查看地点详情、来源与导航入口。
3. 将感兴趣的地点加入收藏或行程。出发前请再次核对开放时间、交通和现场情况。

地图还支持查找附近地点、记录到访和使用当前位置签到。收藏、行程与到访记录仅保存在当前浏览器；换设备或清除浏览器数据后不会自动恢复。定位只用于当前页面计算距离和签到。

## 分享取景地

发现了新的取景地、场景资料，或发现现有地点有误？在地图上点击位置并选择“在此提交取景地”，也可以点击“投稿地点”。依次选择作品、填写地点与场景、检查后直接提交，无需 GitHub 账号。补充已有场景和纠错也可以从地点详情进入。

请尽量提供能支持“这部剧在此取景”的来源链接。集数、时间点和来源不确定时可以留空，维护者会在发布前核对。图片为可选项；上传前请确认有展示许可并写明署名。投稿先进入待审核区，审核通过后才会出现在地图上。

目前投稿接口仍托管在 ChatGPT Sites；如果你所在地区无法访问该服务，地图可能正常打开，但投稿暂时无法提交。

## 使用提醒

目前是试运行版本，已有地点中包含**示意点**，不能据此认定精确拍摄机位。现场可能因营业、施工或私人区域限制而无法进入；请遵守当地规定。

街道底图由 [OpenFreeMap](https://openfreemap.org/) 提供，使用 OpenStreetMap 数据；地图服务不可用时会显示韩国轮廓图。本站参考 [Anitabi](https://navi.anitabi.cn/docs/) 的作品、地标与场景组织方式，不使用其地点数据或截图。
